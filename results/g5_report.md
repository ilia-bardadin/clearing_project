# G5 Report: независимый вывод двух узлов дискретного КК-преобразования

## 1. Дискретная формула

Из METHOD.md, раздел 2:

```
h = w[1] - w[0]
beta[j] = (2/π) · h · Σ_{k≠j} α[k] / (w[k] · (1 − (w[k]/w[j])²))
```

## 2. Вывод для N = 2

Обозначения: `left = w[0]`, `right = w[1]`, `h = right − left`,
`α[0] = a[0]`, `α[1] = a[1]`.

### Узел j = 0 (left)

Единственный вклад: k = 1.

```
beta[0] = (2/π) · h · a[1] / (right · (1 − (right/left)²))
        = (2/π) · h · a[1] / (right · (1 − right²/left²))
        = (2/π) · h · a[1] / (right · (left² − right²)/left²)
        = (2/π) · h · a[1] · left² / (right · (left² − right²))
        = (2/π) · h · a[1] · left² / (right · (left − right)(left + right))
        = (2/π) · (right − left) · a[1] · left² / (right · (left − right)(left + right))
        = (2/π) · a[1] · left² / (right · (left + right)) · (right − left)/(left − right)
        = −(2/π) · a[1] · left² / (right · (left + right))
```

Ключевой момент: `(right − left)/(left − right) = −1`. Знак минус возникает
из-за того, что `right > left`, поэтому `1 − (right/left)² < 0`.

### Узел j = 1 (right)

Единственный вклад: k = 0.

```
beta[1] = (2/π) · h · a[0] / (left · (1 − (left/right)²))
        = (2/π) · h · a[0] / (left · (right² − left²)/right²)
        = (2/π) · h · a[0] · right² / (left · (right² − left²))
        = (2/π) · h · a[0] · right² / (left · (right − left)(right + left))
        = (2/π) · (right − left) · a[0] · right² / (left · (right − left)(right + left))
        = (2/π) · a[0] · right² / (left · (left + right))
```

Знак положительный, так как `1 − (left/right)² > 0`.

### Итоговая формула

```
expected = (2/π) · [ −a[1]·left²/(right·(left+right)),
                      a[0]·right²/(left·(left+right)) ]
```

## 3. Сверка с check_two_nodes

Код из `checks_week7/test_kk_properties.py`:

```python
def check_two_nodes(function, x, a):
    left, right = x
    expected = (2 / np.pi) * np.array([
        -a[1] * left**2 / (right * (left + right)),
        a[0] * right**2 / (left * (left + right)),
    ])
```

**Результат: полное совпадение.** Каждый член, каждый знак, каждый множитель.

## 4. Проверка размерностей

- `α` имеет размерность M⁻¹.
- `w` и `h` — в нм.
- `(w[k]/w[j])²` — безразмерно.
- `1 − (w[k]/w[j])²` — безразмерно.
- Знаменатель `w[k] · (1 − …)` — в нм.
- `beta[j] = (2/π) · h · α / (нм)` = безразм · нм · M⁻¹ / нм = **M⁻¹**. ✓

Множитель `2/π` безразмерен, размерности не меняет.

## 5. Почему проверка обнаруживает пропуск множителя 2/π

Мутант `mutant_prefactor` в тесте:

```python
def mutant_prefactor(x, a):
    return (np.pi / 2) * kk_beta(x, a)
```

Если в реализации пропущен множитель `2/π`, то фактический результат:

```
beta_wrong = h · Σ α[k] / (w[k] · (1 − (w[k]/w[j])²))
           = (π/2) · (2/π) · h · Σ …
           = (π/2) · beta_correct
```

То есть `beta_wrong = (π/2) · beta_correct`, или `beta_correct = (2/π) · beta_wrong`.

Отношение: `π/2 ≈ 1.5708`. Ошибка составляет **~57%**, что многократно превышает
допуск `rtol=1e-9`.

Проверка `np.testing.assert_allclose(actual, expected, rtol=1e-9, atol=1e-11)`
неминуемо отклонит такой результат.

### Почему алгебраические свойства не обнаруживают этот мутант

Множитель `2/π` — константа. Он сокращается в проверках однородности
(`K(s·a) = s·K(a)`) и аддитивности (`K(a+b) = K(a)+K(b)`), так как
умножается на весь результат одинаково. Поэтому G2 (homogeneity, additivity)
не обнаружит пропуск `2/π`.

Только G5 (two_nodes) содержит абсолютное численное сравнение с формулой,
в которой множитель `2/π` зафиксирован. Это делает G5 **независимым
эталонным тестом** для проверки масштаба.
