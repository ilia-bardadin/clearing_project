## G2: Нулевой вход, однородность, аддитивность

### 1. Следует ли из формулы?
Да. Формула линейна по alpha:
- K(0) = (2/π)·h·sum(0/...) = 0
- K(s·a) = (2/π)·h·sum(s·a[k]/...) = s·K(a)
- K(a+b) = (2/π)·h·sum((a[k]+b[k])/...) = K(a)+K(b)

### 2. Стратегия генерации
- `check_zero`: `samples()` → нулевой вектор alpha.
- `check_homogeneity`: `SCALED_ALPHA` → alpha × целое [-4, 4].
- `check_additivity`: `samples(vectors=2)` → два независимых вектора.

### 3. Команды
```
pytest -k "zero or homogeneity or additivity and not catches" -q → 5 passed
```

### 4. Мутанты

| Мутант | Ловушка | Контрпример |
|---|---|---|
| `mutant_offset` = K(a)+1 | K(0)=1 ≠ 0 | (200, 201), [0, 0] |
| `mutant_nonlinear` = K(a*a) | K(s·a) ≠ s·K(a) при a≠const | (200, 201), [0, 1], -1 |
| `mutant_nonadditive` = K(a)+‖a‖ | K(a+b) ≠ K(a)+K(b) | (200, 201), [0, 1], [1, 0] |

### 5. Результат
**Принято.** Все три свойства и мутанты работают.

## G3: Инвариантность при общем масштабе длин волн

### 1. Следует ли из формулы?
Да. При w → q·w (q > 0):
- h → q·h
- w[k]/w[j] = (q·w[k])/(q·w[j]) — не меняется
- Знаменатель: (q·w[k])·(1 - (w[k]/w[j])²) = q·[w[k]·(1 - ...)]
- Итого: (2/π)·(q·h)·sum(alpha[k]/(q·denom)) = (2/π)·h·sum(alpha[k]/denom)
- q сокращается. K(q·w, a) = K(w, a).

### 2. Стрататегия генерации
`SCALED_GRID` → сетки + множитель 0.001 или 1000. Покрытие экстремальных
масштабов из SUBGOALS.md.

### 3. Команда
```
pytest -k "wavelength_scale and not catches" -q → 1 passed
```

### 4. Мутант
`mutant_wrong_step` = K(a)/h — делит на шаг. При масштабировании h меняется,
но K(a) не меняется (инвариантность), поэтому K(a)/h меняется.

### 5. Контрпример
`(200, 201), [0, 1], 0.001` — масштабирование сетки в 1000 раз меняет h,
мутант возвращает другое значение.

### 6. Результат
**Принято.** Свойство и мутант работают.

## G4: Исключение диагонального вклада

### 1. Следует ли из формулы?
Да. Диагональный член (k=j) исключён через `np.where(np.eye(...), 0, 1/denom)`.
При входе с единственным ненулевым узлом j:
- Все слагаемые k≠j равны нулю (alpha[k]=0)
- Следовательно beta[j] = 0

### 2. Стратегия генерации
`impulses()` → сетка + случайный индекс + случайная амплитуда.
Покрытие всех узлов сетки.

### 3. Команда
```
pytest -k "diagonal and not catches" -q → 1 passed
```

### 4. Мутант
`mutant_diagonal` = K(a) + a — добавляет диагональный вклад обратно.
При импульсе в узле j: K(a)[j] = 0, но mutant даёт a[j] ≠ 0.

### 5. Контрпример
`(200, 201), 0, 1.0` — импульс в узле 0 с амплитудой 1.0.
Правильный результат: [0, 0.32069919], мутант: [1, 0.32069919].

### 6. Результат
**Принято.** Свойство и мутант работают.
