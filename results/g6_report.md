## 2. Анализ каждой пары

### 2.1 zero — mutant_offset

| Поле | Значение |
|---|---|
| Свойство | `K(0) = 0` (atol=1e-12, rtol=0) |
| Мутант | `kk_beta(x, a) + 1` — константное смещение |
| Ошибка модели | Систематическая калибровочная погрешность: к результату прибавляется константа, не зависящая от входа |
| Контрпример | `x = [200, 201]`, `a = [0, 0]` |
| `kk_beta(x, 0)` | `[0, 0]` — проходит |
| `mutant(x, 0)` | `[1, 1]` — отклоняется (ошибка = 1, допуск 1e-12) |

**Почему работает:** нулевой вход обязывает `kk_beta` дать строго ноль. Смещение нарушает это требование.

---

### 2.2 homogeneity — mutant_nonlinear

| Поле | Значение |
|---|---|
| Свойство | `K(s·a) = s·K(a)` (rtol=1e-9, atol=1e-11) |
| Мутант | `kk_beta(x, a * a)` — возведение alpha в квадрат |
| Ошибка модели | Нелинейная обработка входа: сигнал искажается перед преобразованием (например, детектирование мощности вместо амплитуды) |
| Контрпример | `x = [200, 201]`, `a = [0, 1]`, `scale = -1` |
| `kk_beta(x, -a)` | `[0.3159, 0]` |
| `-1 · kk_beta(x, a)` | `[0.3159, 0]` — совпадает |
| `mutant(x, -a)` | `kk_beta(x, [0, 1]) = [-0.3159, 0]` |
| `-1 · mutant(x, a)` | `-1 · kk_beta(x, [0, 1]) = [0.3159, 0]` |
| Расхождение | `[-0.3159, 0]` vs `[0.3159, 0]` — знаки противоположны |

**Почему работает:** возведение в квадрат уничтожает знак alpha. При `scale = -1` мутант получает `(-a)² = a²`, тогда как правая часть формулы однородности меняет знак.

### 2.3 additivity — mutant_nonadditive

| Поле | Значение |
|---|---|
| Свойство | `K(a+b) = K(a) + K(b)` (rtol=1e-9, atol=1e-11) |
| Мутант | `kk_beta(x, a) + ‖a‖` — прибавление нормы входа |
| Ошибка модели | Зависимость результата от абсолютной интенсивности сигнала, а не только от формы спектра (например, насыщение детектора) |
| Контрпример | `x = [200, 201]`, `a = [0, 1]`, `b = [1, 0]` |
| `‖a+b‖` | `√2 ≈ 1.4142` |
| `‖a‖ + ‖b‖` | `1 + 1 = 2.0` |
| Расхождение | `1.4142 ≠ 2.0` — норма не аддитивна |

**Почему работает:** евклидова норма не удовлетворяет `‖a+b‖ = ‖a‖ + ‖b‖` (равенство только при коллинеарных неотрицательных векторах).

### 2.4 wavelength_scale — mutant_wrong_step

| Поле | Значение |
|---|---|
| Свойство | `K(q·w, a) = K(w, a)` для `q > 0` (rtol=1e-9, atol=1e-11) |
| Мутант | `kk_beta(x, a) / (x[1] - x[0])` — деление на шаг сетки |
| Ошибка модели | Моделирует отсутствие множителя шага `h` в формуле. |
| Контрпример | `x = [200, 201]`, `a = [0, 1]`, `scale = 0.001` |
| `kk_beta(0.001·x, a)` | `[-0.3159, 0]` |
| `kk_beta(x, a)` | `[-0.3159, 0]` — совпадает |
| `mutant(0.001·x, a)` | `[-315.936, 0]` |
| `mutant(x, a)` | `[-0.3159, 0]` |
| Расхождение | фактор 1000 = 1/scale |

**Почему работает:** при масштабировании сетки в `q` раз шаг становится `q·h`. Мутант делит на `q·h` вместо `h`, давая результат, увеличенный в `1/q` раз.

### 2.5 diagonal — mutant_diagonal

| Поле | Значение |
|---|---|
| Свойство | Для входа с единственным ненулевым узлом `j`: `result[j] = 0` (atol=1e-12, rtol=0) |
| Мутант | `kk_beta(x, a) + a` — прибавление входа к выходу |
| Ошибка модели | Включение диагонального члена (k = j) в сумму КК-преобразования |
| Контрпример | `x = [200, 201]`, `index = 0`, `amplitude = 1.0` |
| `kk_beta(x, a)[0]` | `0.0` — проходит |
| `mutant(x, a)[0]` | `0 + 1.0 = 1.0` — отклоняется |

**Почему работает:** при импульсном входе диагональный член в мутанте равен `a[index] = 1.0`, что нарушает требование строгого нуля.

---

### 2.6 two_nodes — mutant_prefactor

| Поле | Значение |
|---|---|
| Свойство | Аналитический ответ для двух узлов: `(2/π) · [...]` (rtol=1e-9, atol=1e-11) |
| Мутант | `(π/2) · kk_beta(x, a)` — обратный множитель |
| Ошибка модели | Пропуск множителя `2/π` в реализации (фактический множитель = 1, что эквивалентно умножению на `π/2` относительно правильной формулы) |
| Контрпример | `x = [200, 201]`, `a = [0, 1]` |
| `kk_beta` | `[-0.3159, 0]` |
| `expected` | `[-0.3159, 0]` — совпадает |
| `mutant` | `[-0.4963, 0]` |
| Расхождение | `mutant / expected = π/2 ≈ 1.5708` — ошибка ~57% |

**Почему работает:** множитель `π/2` вместо `2/π` даёт отношение к правильному ответу `π/2 ≈ 1.5708`, относительная ошибка `π/2 - 1 ≈ 0.5708` (57.08%). Ошибка многократно превышает допуск `rtol=1e-9`.

### 2.7 output — mutant_shape

| Поле | Значение |
|---|---|
| Свойство | Выход имеет правильную форму, действителен и конечен |
| Мутант | `kk_beta(x, a)[:-1]` — усечение последнего элемента |
| Ошибка модели | Ошибка off-by-one: выходной массив короче входного |
| Контрпример | `x = [200, 201]`, `a = [0, 0]` |
| `kk_beta` shape | `(2,)` — проходит |
| `mutant` shape | `(1,)` — отклоняется (AssertionError: Wrong output shape) |

**Почему работает:** проверка `assert value.shape == a.shape` немедленно отклоняет массив неправильной длины.

## 3. Почему одной линейности недостаточно для обнаружения пропуска множителя 2/π

Это ключевой вопрос, поднятый в SUBGOALS.md и подтверждённый отчётом G5.

### 3.1 Алгебраические свойства инвариантны к константному множителю

Функция `K'(x, a) = c · K(x, a)` для любой константы `c ≠ 0` удовлетворяет:

- **Нулевой вход:** `K'(x, 0) = c · K(x, 0) = c · 0 = 0` ✓
- **Однородность:** `K'(x, s·a) = c · K(x, s·a) = c · s · K(x, a) = s · K'(x, a)` ✓
- **Аддитивность:** `K'(x, a+b) = c · K(x, a+b) = c · (K(x,a) + K(x,b)) = K'(x,a) + K'(x,b)` ✓
- **Масштаб сетки:** `K'(q·w, a) = c · K(q·w, a) = c · K(w, a) = K'(w, a)` ✓
- **Диагональ:** `K'(x, impulse_j) = c · 0 = 0` ✓

Все пять алгебраических свойств сохраняются при умножении на любую константу. Поэтому пропуск множителя `2/π` (эквивалентный умножению на `π/2`) **не обнаруживается** ни одним из свойств G1–G4.

### 3.2 G5 — единственный абсолютный тест

Проверка `two_nodes` (G5) сравнивает результат с **абсолютно заданной формулой**, в которой множитель `2/π` зафиксирован:

```python
expected = (2 / np.pi) * np.array([
    -a[1] * left**2 / (right * (left + right)),
    a[0] * right**2 / (left * (left + right)),
])
```

Любое отклонение множителя приводит к относительной ошибке `|c - 2/π| / (2/π)`. Для мутанта `mutant_prefactor` (`c = π/2`) ошибка составляет `π/2 - 1 ≈ 0.5708` (57.08%), что многократно превышает допуск `rtol=1e-9`.

### 3.3 Связь с отчётом G5

Отчёт G5 подтверждает:
1. Независимый вывод формулы для двух узлов **полностью совпадает** с `check_two_nodes`.
2. Знаки, размерности, множитель `2/π` и сокращение шага `h` подтверждены.
3. Проверка обнаруживает пропуск `2/π`, так как содержит абсолютное численное сравнение, в то время как алгебраические свойства множитель не проверяют.

## 5. Ограничения

- Контрпримеры найдены Hypothesis с `max_examples=1000`, `derandomize=True`. Это детерминированные, воспроизводимые контрпримеры, но конечный прогон не исчерпывает всю область входов.
- Для `wavelength_scale` и `two_nodes` некоторые компоненты контрпримера равны нулю (например, `a[0]=0` в двухузловом случае), что упрощает анализ. В реальных данных все узлы ненулевые.
- Мутанты сконструированы как модификации `kk_beta`, а не как независимые функции. Это означает, что они наследуют все свойства `kk_beta` кроме одного проверяемого.
- Проверка не оценивает точность непрерывного интеграла КК-преобразования — только воспроизведение фиксированной дискретной суммы.

Все семь мутантов обнаружены соответствующими проверками. Каждый контрпример проходит на исходной функции `kk_beta` и отклоняет мутанта. Алгебраические свойства (G1–G4) инвариантны к константному множителю, поэтому только G5 (two_nodes) обнаруживает пропуск множителя `2/π`.
