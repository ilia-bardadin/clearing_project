## Библиография (с. 19–20)

Файл part_07.md содержит исключительно библиографический список из обзорной статьи (iScience 24, 102178, March 19, 2021). Основной научный текст отсутствует — представлены только цитируемые работы по оптическому просветлению тканей, трёхмерной микроскопии и связанным методам. Список включает ~100+ ссылок на статьи из журналов Cell, Nature Methods, Biomedical Optics Express и других, охватывающих методы CLEAR, CUBIC, iDISCO, PACT, ClearSee и другие подходы к просветлению биологических тканей. Отдельных главных утверждений, методов или результатов в данном фрагменте нет — это справочный раздел обзорной статьи.
