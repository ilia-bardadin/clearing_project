## Список литературы (с. 21–21)

Данная страница содержит исключительно библиографический список из 16 работ по опическому просветлению тканей, иммуномечению орган-масштабных образцов и глубокой микроскопии (с. 21). Основные направления цитируемых исследований: ускорение PACT-просветления мышиного мозга (с. 21), многодither когерентная адаптивная техника для глубокой двухфотонной микроскопии (с. 21), количественный анализ дегидратации свиной кожи для оценки механизма оптического просветления (с. 21), крупное переключаемое окно просветления черепа для in vivo-визуализации (с. 21), быстрая водная система MACS для 3D-картирования интактных органов (с. 21), ультрабыстрый метод оптического просветления для трёхмерной визуализации с клеточным разрешением (с. 21), а также клеточное и молекулярное зондирование интактных человеческих органов (с. 21). Работа не содержит главного утверждения, метода или результата — это справочный раздел обзорной статьи.
