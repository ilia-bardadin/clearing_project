# Получить формулу и PubChem CID глицерина из Wikidata

Готово, когда: есть заметка `type: ЗапросКГрафу` с текстом запроса SPARQL к Wikidata; в `notes/Глицерин.md` нет поля `wikidata` во frontmatter и есть строка «[источник] Wikidata: …» с идентификатором сущности, формулой (P274) и PubChem CID (P662).
Не входит: данные Wikidata для других агентов.

## Итог
Сущность глицерина в Wikidata — Q132501. Запрос SPARQL записан заметкой [[Запрос 2026-10-18 glycerol Wikidata]]; в [[Глицерин]] поле `wikidata` убрано из frontmatter, добавлена строка «[источник] Wikidata: Q132501 — glycerol; P274: C₃H₈O₃; P662: 753».
Проверка: повторный запрос SPARQL к query.wikidata.org 2026-10-18 вернул formula = C₃H₈O₃, pubchem = 753; `grep -c "^wikidata:" notes/Глицерин.md` — 0.
