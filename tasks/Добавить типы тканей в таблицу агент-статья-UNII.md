# Добавить типы тканей в таблицу агент — статья — UNII

Запрос пользователя: «теперь добавь в таблицу типы тканей, на которые применяли эти агенты»

Готово, когда: в `review/agent_unii.csv` добавлен столбец «ткань» с типом ткани для каждой строки (комбинация агент × статья), тип ткани соответствует статье из `paper/library/`; заметки тканей созданы в `notes/` и связаны с агентами/статьями.
Не входит: пересчёт коэффициентов, КК, обзор литературы.
