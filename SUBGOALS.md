# Дерево подцелей: свойства дискретного КК-преобразования

## Корень

На установленной области входов функция kk_beta воспроизводит фиксированное
дискретное КК-преобразование, удовлетворяет его математическим свойствам,
а каждая проверка обнаруживает соответствующую внесённую ошибку.

Проверяется дискретная формула из METHOD.md, без изменения весов,
исключения диагонали, диапазона интегрирования и множителя 2/pi.

## Проверка постановки

**Постановку проверил автор:** да; проверил.

Подготовлено для сверки:

- alpha = dn''/dc и beta = dn'/dc, обе величины в M^-1.
- Преобразование возвращает beta без умножения на концентрацию.
- Отрицательные alpha и beta допустимы.
- Не предполагаются неотрицательность beta, монотонность beta по длине
  волны или сохранение суммы beta.
- Согласованность единиц проверяется через общий масштаб координат сетки.
  Это свойство формулы, а не наличие поддержки объектов с единицами в API.
- Два узла входят в допустимую область.
- Проверка некорректных входов и требование отклонять неравномерную сетку
  в эту постановку не входят.
- Тесты не устанавливают точность непрерывного интеграла или сходимость схемы.

## Область генерации

- Число узлов: 2–48.
- Начальная длина волны: 200–1200 нм.
- Шаг: 0.25–10 нм.
- Сетка: wavelength[j] = start + j*step.
- alpha: конечные числа в [-10, 10], включая ноль и отрицательные значения.
- Для аддитивности независимо генерируются два массива alpha.
- Множитель alpha: целое число от -4 до 4.
- Для проверки масштаба сетки используются множители 0.001 и 1000.
- NaN, бесконечности и субнормальные alpha не генерируются.

## Свойства

1. Нулевой вход: K(0) = 0.
2. Однородность: K(s*a) = s*K(a).
3. Аддитивность: K(a+b) = K(a)+K(b).
4. Масштаб координат: K(q*w, a) = K(w, a), q > 0.
5. Исключение диагонали: для входа с единственным ненулевым узлом j
   результат в узле j равен нулю.
6. Аналитический ответ для двух узлов совпадает с реализацией.
7. Результат имеет правильную форму, действителен и конечен.

Свойства сравниваются с численным допуском.
Нулевой вход и диагональ: atol=1e-12, rtol=0.
Остальные численные сравнения: atol=1e-11, rtol=1e-9.

Алгебраические свойства сами по себе не определяют правильный масштаб:
их может удовлетворять функция с пропущенным множителем 2/pi.
Поэтому обязательны двухузловой ответ и существующий эталон недели 6.

## Организация работы

- src/solution.py, METHOD.md, checks/ и stain_data/ сохраняются.
- Новые тесты размещаются в checks_week7/.
- Использование checks_week7/ вместо checks/ — явное отклонение от пути
  в учебном шаблоне из-за действующего запрета изменять checks/.
- Независимую подцель G5 предполагается поручить вспомогательному агенту.
  Пока такое поручение не выполнялось.
- Каждая попытка записывается в ATTEMPTS.md.
- После трёх неудачных попыток на одной подцели применяется правило
  трёх попыток: изменение плана фиксируется отдельной записью.
