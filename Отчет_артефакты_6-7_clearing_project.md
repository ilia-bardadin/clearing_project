## Артефакт 6. Расчёт спектров β для четырёх красителей

По спектру `α = dn″/dc` рассчитывали `β = dn′/dc`. Обе величины выражены в М⁻¹. Использовали фиксированную дискретную формулу Крамерса–Кронига на исходной равномерной сетке каждого спектра. Вклад узла в собственное значение исключался, а остальные узлы учитывались с полным весом шага сетки. Критерии приёмки зафиксированы до первого прогона в коммите `6709be0`.

| Краситель | Число узлов | Максимальная абсолютная ошибка по эталонным точкам, М⁻¹ |
|---|---:|---:|
| Тартразин | 587 | 2,08 × 10⁻¹⁷ |
| Индигокармин | 1190 | 2,08 × 10⁻¹⁷ |
| Метиленовый синий | 301 | 5,55 × 10⁻¹⁷ |
| Флуоресцеин | 1001 | 1,11 × 10⁻¹⁶ |

Всего получено **3079 значений β**. Верификатор сверил контрольные суммы входов и эталона, проверил сетки, нулевой вход, удвоение и аддитивность. Для каждого красителя он сравнил шесть точек с эталоном и весь сохранённый спектр с результатом функции. Полная проверка завершилась с вердиктом **`ПРОЙДЕНО`**, код 0.

**Демонстрация обнаружения ошибки.** В коммите `c9a5fb8` из `kk_beta` намеренно убрали множитель `2/π`. В точке минимума для тартразина получилось −0,229176 М⁻¹ при эталонном значении −0,145898 М⁻¹. Модуль результата вырос примерно на 57,1%, и верификатор завершился с кодом 1. После восстановления множителя в коммите `6810adc` проверка прошла с кодом 0. Ветка `exp-verifier-fail` указывает на исправление, ошибочная версия доступна по хешу `c9a5fb8`.

При первом прогоне обнаружилась и ошибка записи CSV: формат `.12g` округлял длины волн индигокармина сверх допуска. Переход на `.17g` устранил расхождение. Этот случай описан в разделе 9 `METHOD.md`.

**Оценка времени.** По замерам на сетках из 301 и 1190 узлов получен показатель роста времени `κ ≈ 2,056`. Прогноз суммы времён вычислительной функции для четырёх спектров составил 9,02 мс, сумма замеров — 7,48 мс. Это оценка по одному замеру на размер, без учёта запуска Python и файлового ввода-вывода.

## Артефакт 7. Проверка свойств преобразования с Hypothesis

**Направление B** — вычислительный верификатор на свойствах. Hypothesis генерировал равномерные сетки из 2–48 узлов с началом в диапазоне 200–1200 нм, шагом 0,25–10 нм и конечными значениями `α` от −10 до 10 М⁻¹.

| Что проверялось | Какую внесённую ошибку обнаружил тест |
|---|---|
| Форма результата, действительные и конечные значения | Удаление последнего элемента |
| Нулевой вход даёт нулевой результат | Прибавление постоянного смещения |
| Масштабирование `α` так же масштабирует `β` | Возведение входных значений в квадрат |
| Преобразование суммы равно сумме преобразований | Прибавление нормы входного вектора |
| Общий масштаб длин волн сохраняет результат | Пропуск множителя шага сетки |
| Узел с одиночным ненулевым входом не даёт вклада в собственное значение | Возврат диагонального вклада |
| Значения для двух узлов совпадают с независимой формулой | Пропуск множителя `2/π` |

Нулевой вход, однородность и аддитивность сохраняются при умножении всего результата на константу. Поэтому для проверки численного масштаба отдельно вывели формулу для двух узлов. Она обнаружила тот же пропуск `2/π`, который на неделе 6 выявило сравнение с эталоном.

Итоговый набор содержит **14 успешных тестов**: семь проверок свойств и семь проверок чувствительности к внесённым ошибкам. Для каждой ошибки Hypothesis нашёл пример, который проходит на исходной функции и отклоняет ошибочную версию. Все подцели G1–G7 закрыты. Порог трёх неудачных попыток по одной подцели достигнут не был. Повторная проверка входных данных и четырёх спектров также прошла.
